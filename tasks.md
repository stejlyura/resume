# Подробный план разработки SPA "Конструктор Резюме" с Git-like ветвлением по методологии FSD

Этот документ представляет собой подробное руководство к действию для ИИ/разработчика. Каждая задача разделена на конкретные шаги, содержит требования к типам данных, ожидаемое поведение и критерии приемки, чтобы минимизировать галлюцинации и отклонения от архитектуры.

---

## Архитектура проекта (Feature-Sliced Design)
Проект должен быть строго разделен на слои внутри папки `src/`:
- `src/shared` — переиспользуемые UI-элементы, хуки, утилиты. Без привязки к бизнес-логике.
- `src/entities` — типы данных, интерфейсы и базовые сущности резюме.
- `src/features` — интерактивные фичи с бизнес-логикой (Drag-and-Drop, PDF-export, Git-branching, Auto-save).
- `src/widgets` — крупные блоки интерфейса (Header, Summary, ExperienceEditor, BranchVisualizer).
- `src/app` — глобальные провайдеры, стили (`index.css`), точка входа (`main.tsx`).

Дополнительно в корне проекта создается папка `server/` для легковесного Node.js/Express бэкенда, обеспечивающего безопасную интеграцию с MongoDB Atlas.
