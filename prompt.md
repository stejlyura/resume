ТЗ на разработку SPA "Конструктор Резюме" (Production-Ready)

1. Концепция

Разработать SPA для создания ATS-friendly резюме. Главный фокус — модульность: каждый блок резюме — это независимая сущность, редактируемая отдельно.

2. Технический стек

Core: React (Vite), TypeScript.

Стили: Tailwind CSS (внутри одного файла).

State Management: Zustand (хранение состояния всех блоков резюме).

Form Management: react-hook-form (для обработки инпутов и валидации).

PDF Generation: @react-pdf/renderer (для генерации чистого, ATS-дружелюбного PDF).

Архитектура: Логическое разделение FSD внутри одного файла:

shared: UI-компоненты (input, button, textarea), хуки (useLocalStorage).

entities: Интерфейсы Resume, ResumeBlock.

features: Логика Drag-and-Drop, PDF-export, Auto-save.

widgets: Header, Summary, ExperienceEditor.

3. Функциональные требования

Модульность:

Шапка (имя, контакты).

Summary (textarea).

Experience (динамический список блоков с Drag-and-Drop).

Редактирование:

Каждый блок — это textarea с поддержкой форматирования (жирный, курсив — через Markdown-разметку, которая будет конвертироваться в PDF).

Автосохранение в localStorage с debounce (500мс).

Метаданные: Отдельные поля ввода для заголовка файла и мета-тегов (ключевые навыки для ATS).

Экспорт: Кнопка "Скачать PDF". Файл должен быть семантически структурирован (стандартный шрифт, отсутствие сложных графических элементов) для корректного чтения ATS-системами.

4. Требования к UI/UX

Минималистичный интерфейс (Dark/Light mode опционально).

Индикатор сохранения ("Saved" / "Saving...").

Возможность создания нескольких версий резюме (переключение через селект).

каждое рез.ме иемеют ветки как в гитхаб. Ветки можно называть а так же имеют визаулизацию юх для удобной навигации
