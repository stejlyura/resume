## 🚀 Сильные слова и фразы для ATS (ATS Action Verbs)
*Используйте эти глаголы действия при описании своего опыта, чтобы резюме выглядело убедительно:*

* **Вместо «делал» (worked on) используйте:**
  * `**Led**` (Руководил) — *Led the development...*
  * `**Engineered**` (Спроектировал/разработал) — *Engineered a scalable state architecture...*
  * `**Optimized**` (Оптимизировал) — *Optimized web performance...*
  * `**Implemented**` (Внедрил) — *Implemented CI/CD pipelines...*
  * `**Redesigned**` (Переработал дизайн/архитектуру) — *Redesigned the application flow...*
  * `**Decreased / Increased**` (Уменьшил / Увеличил) — *Decreased load times by...*
  * `**Mentored**` (Обучал) — *Mentored junior developers...*

## 💡 Как правильно использовать Markdown в конструкторе?
1. В полях **Summary** и **Description** (в Опыте работы) вы можете свободно использовать:
   * `**жирный текст**` для выделения стека технологий, процентов, чисел и ключевых результатов (например, **35%**, **React**, **Lead**).
   * `*курсив*` для второстепенного выделения (например, названий методологий или ролей).
2. Разметка автоматически преобразуется в PDF-документ с соответствующими шрифтами (Helvetica-Bold и Helvetica-Oblique), что делает его визуально структурированным и приятным для чтения человеком, оставаясь на 100% распознаваемым для ATS (роботов-рекрутеров).
